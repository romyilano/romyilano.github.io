## Naming Conventions

**Files:**
- HTML: `index.html` (single root file following GitHub Pages convention)
- CSS: `styles.css` (single stylesheet, lowercase)
- JavaScript: `script.js` (single script file, lowercase)
- Assets: descriptive names with extensions (`.svg`, `.jpg`, `.jpeg`)

**CSS Classes:**
- BEM-inspired: `[block]__[element]--[modifier]`
  - Examples: `.site-nav__logo`, `.project-card__title`, `.hero__avatar-highlight`
  - Elements joined with double underscore (`__`)
  - Modifiers joined with double hyphen (`--`)
  - Single hyphens within names: `.site-nav`, `.project-card`

**HTML Data Attributes:**
- Purpose-driven: `data-[feature]`
  - `data-reveal`: Elements to animate on scroll
  - Style variables for tilted cards: `style="--tilt: 1deg"`

**CSS Custom Properties (Variables):**
- Grouped by category with `--` prefix
  - Colors: `--color-bg`, `--color-accent`, `--color-muted`
  - Typography: `--font-display`, `--text-heading`, `--weight-bold`
  - Spacing: `--space-xs`, `--space-lg`, `--space-3xl`
  - Animations: `--reveal-duration`, `--ticker-duration`

## Where to Add New Code

**New Section/Component:**
1. Add HTML section to `index.html` (between existing `<section>` tags)
2. Follow semantic HTML: use `<section>`, `<article>`, `<div class="section">` patterns
3. Use BEM-style classes: `.new-section`, `.new-card__title`, etc.
4. Add CSS rules to `styles.css` (append to file or organize by component)
5. Add data attributes if animations needed: `data-reveal` for scroll animations

**New Static Asset:**
1. Place in `public/assets/images/` (for images) or `public/assets/icons/` (for icons)
2. Use descriptive filename: `project-name-hero.jpg` or `icon-name.svg`
3. Reference in `index.html` with relative path: `public/assets/images/...`

**New Interactive Feature:**
1. Add JavaScript to `script.js` following existing patterns:
   - Detect elements via data attributes or IDs
   - Use vanilla browser APIs (no jQuery, no framework)
   - Respect `prefers-reduced-motion` via `prefersReducedMotion()` function
   - Add ARIA attributes to HTML for accessibility
2. Initialize in bottom of `script.js` (lines 57-58): call `initFeatureName()`

**New CSS Design Token:**
- Add to `:root` selector in `styles.css:17-97`
- Follow naming convention: `--[category]-[name]`
- Document group (colors, fonts, spacing, etc.)
